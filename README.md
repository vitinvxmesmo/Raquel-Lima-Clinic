<h2>Sobre o projeto</h2>

<p>
A landing page da <strong>Raquel Lima Clinic</strong> foi projetada e desenvolvida
com foco em posicionamento digital, experiência do usuário, performance e conversão.
</p>

<p>
O projeto combina uma direção visual sofisticada com uma estrutura técnica preparada
para mecanismos de busca, dispositivos móveis e ferramentas de análise.
</p>

<h3>Principais características</h3>

<ul>
  <li>Design responsivo e experiência mobile</li>
  <li>Identidade visual personalizada</li>
  <li>SEO técnico e SEO local</li>
  <li>Estrutura semântica otimizada</li>
  <li>Schema.org e dados estruturados</li>
  <li>Otimização de imagens e performance</li>
  <li>Open Graph para compartilhamento</li>
  <li>Conversão direcionada para agendamento</li>
  <li>Preparação para Google Analytics 4</li>
  <li>Preparação para Google Search Console</li>
  <li>Preparação para Microsoft Clarity</li>
  <li>Acessibilidade e boas práticas de desenvolvimento</li>
</ul>
